# HoyoDeCrimen.clean

This repository contains the data pipeline for [hoyodecrimen.com](https://hoyodecrimen.com). It provides scripts to automatically download, process, and clean the crime dataset published by the Mexico City Attorney General's Office (FGJ-CDMX).

## Data Source

* **Dataset:** [Carpetas de investigación FGJ de la Ciudad de México](https://www.fgjcdmx.gob.mx/transparencia/incidencia-delictiva)
* **Publisher:** Fiscalía General de Justicia de la Ciudad de México (FGJ-CDMX)

## Purpose

The cleaned and standardized dataset generated by these scripts powers the visualizations and analyses on Hoyo de Crimen, helping track and understand crime trends in Mexico City.
